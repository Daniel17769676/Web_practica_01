## ✨ Sobre este Proyecto

Este es mi primer sistema completo desarrollado con Django, creado para aprender y resolver un problema real: la gestión manual de reservas en pequeños negocios.

---

## 📌 Problema que Resuelve

Elimina la gestión manual de reservas (correos, planillas)

---

## 🧩 ¿Qué hace el sistema?

- Para negocios:
  - 📅 Programa horarios disponibles
  - 👀 Ve reservas en tiempo real

- Para clientes:
  - 📝 Reserva en 3 pasos simples
  - 🔔 Recibe recordatorios automáticos (a través de archivos `.ICS`.)
